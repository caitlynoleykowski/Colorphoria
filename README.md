# Filler
Graphic editing application used to fill an image with colors as well as other features
Feature List:
1.  Choose Image File
2.  Capture Image from Camera
3.  Threshold
4.  Random Line Fill
5.  Random Flood Fill
6.  Random Bleed Fill
7.  Rotation Left/Right
8.  Undo/Redo
9.  Download Image
10. Share Image
